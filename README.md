# Materia

双击本文件夹中的「Materia.exe - 快捷方式」启动桌面程序。请保留整个 materia 文件夹。

程序源码及桌面版位于 material-atlas。原有文献库保存在 material-atlas/release/Materia-win32-x64/文献库，快捷方式启动的版本会继续使用该文献库。

快捷方式对应的程序资源已升级到 v1.4.5，支持恒星、带环行星、远景星野和双色星云。完整主题包仍从「主题与字体」导入；星图形态选择「跟随主题包」。可制作新主题的接口说明见 material-atlas/GRAPH_THEME_API.md，升级前程序备份保存在 material-atlas/.local/cosmos-upgrade-backup。

已融合 todo2 的 AI 研究助手、Markdown 对话和本地聊天历史，保留字体、主题、阅读器、收藏夹和性能绘图。图谱改为简洁圆点与直线，普通拖动自然释放，Shift 拖动固定。

合并前 todo2 的可恢复备份和校验清单位于 material-atlas/.local/merge-backup，具体使用说明见 material-atlas/README.md 和 material-atlas/AI_AGENT.md。
