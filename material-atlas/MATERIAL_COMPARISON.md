# 按材料选择：来源独立的性能对比与作图

## 主界面材料列表与分组

主界面在「星图视图 / 文献列表」旁新增「材料列表」。每行对应一个已录入材料，独立显示成分、性能参数和来源文献；同名但来源不同的材料分别呈现。整行勾选可选取该材料的所有样品 / 条件，展开「查看 / 细选样品与测试条件」可以只选其中一部分。点击「参数对照」或「对比与作图」直接使用当前材料选择，原文献勾选独立保留。

列表支持按材料、成分、性能、样品、条件和来源文献搜索，可只看已选，全选包含当前筛选的所有材料，不限于已显示的前 100 个。「清空材料选择」一次取消全部材料勾选，包括筛选外和失效选择。文献列表上方也直接提供「清空选择」，一次取消所有文献勾选。

「新建分组」可建立研究主题，并将当前所选材料加入。通过「归入 / 移出分组」批量移动材料；选中分组后，从「分组设置」重命名或删除分组。每个材料归入一个分组，其全部样品共用归属；分组以文献 ID 和材料 ID 记录，改名或修改测试条件不会丢失归属。删除分组只解除归属，材料、参数及来源文献保留。

材料分组与两份选择随文献库保存，重启保留。完整文献备份包含材料分组；恢复时与已有分组合并。已有版本备份仍可恢复。更新桌面程序后请退出并重新启动 Materia。

从「性能对比与作图」进入，顶部可切换「按文献 / 按材料」。文献列表勾选后的主对比按钮继续按文献操作；工具栏与侧栏入口记住最近使用的方式。两份选择分别保存，切换方式不会清空另一份选择。

## 先筛选，再选择具体材料

「按材料」列出全库已经录入的材料，不需要先选整篇文献。每条记录独立显示：

- 材料的真实名称和成分；不把文献标题、作者、年份或 DOI 拼到材料名称中。
- 样品与测试条件。
- 「来源文献」标题、期刊与年份；点击标题可打开完整文献信息，再进入 PDF 阅读。
- 已录入的性能记录摘要；空白或无效数值会明确标注，不因无法绘图而在查找阶段消失。

搜索支持名称、成分、描述、样品和条件；也可按性能参数、单位及来源文献筛选。性能参数目录和文献参数筛选摘要中均有「直接选材料」入口，带入当前参数。

同一材料有多组样品或条件时，分别列为可选择的项目。比如同一材料的 S1 / 室温与 S2 / 热处理可独立勾选。界面同时显示选择项数、真实材料数和来源文献篇数。一个材料的多组样品条件不会被误计为多个原始材料。

「全选当前结果」包含所有匹配项目，不限于当前显示的前 100 项；可继续加载。筛选隐藏的已选项仍保留，界面会提示。可只看已选、逐项移除或清空材料选择。

## 对照与绘图

选好后进入参数对照或科研绘图，沿用年份、IF、性能参数坐标，以及折线、散点、柱状图、误差棒和图像导出功能。

- 对照表每列对应一项明确的材料、样品与条件，来源文献有独立一行。
- 查找参数只是筛选材料资格；选中项目的其他已录入参数同样可以用于后续对比与坐标。
- 同名但不同单位的参数继续分开处理，不自动换算。
- X / Y 性能参数只在同一材料 ID、样品及完全相同的条件内配对。没有对应坐标、只有不同条件的候选值或存在多值歧义时，逐项列出原因，不猜配、不平均。
- 默认按材料分组时，折线不跨不同材料、样品或条件。也可明确选择按测试条件或全部观测分组来比较跨文献年份趋势；界面会提示独立材料 / 来源，所有原始记录仍独立保留。
- 图表提示框独立显示材料、来源文献、期刊、年份、DOI、样品、条件和原记录位置。柱状图标签以简洁的材料 / 样品为主。
- 原始测量 CSV、当前图数据 CSV、参与清单 CSV 保留独立的材料名称、材料 ID、来源文献和选择项标识；图数据还保留 X / Y 记录与条件。

同样的条件文本按原样区分，不推测「RT」和「Room temperature」等写法的语义等价。需要配对时，请先在原数据中核实并统一条件；也可分别用柱状图比较各组观测。

## 保存与兼容

选择项通过文献 ID、材料 ID、样品与条件关联，不依赖名称。同名的不同来源、不同材料 ID 或不同样品条件均可区分；改名或修改成分不会使同 ID 的选择串到其他材料。

材料删除或样品 / 条件改变后，原选择显示为失效，不按同名项目自动重配。用户可明确移除失效选择。旧版未保存过材料选择时，默认进入原有按文献方式。

当前方式、材料选择及筛选保存在文献库 `library.json` 的独立 `comparisonState` 设置中；原来的 `comparisonSelection` 文献勾选保持独立。保存失败可重试，也可还原上次已保存的选择；桌面窗口关闭前会等待选择保存。

界面使用已有主题与字体，源材料、性能记录、文献、PDF 和笔记不因勾选或模式切换而改写。更新后请重新启动 EXE，以启用新的选择设置存储接口。
