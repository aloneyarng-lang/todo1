# Materia · 材料文献星图（Windows 桌面版）

## 宇宙星图主题接口（v1.4.5）

完整主题包现可使用带光芒的恒星、倾斜光环行星、远景星野与双色星云。原有主题导入入口继续适用；导入后将星图形态设为「跟随主题包」。星图设置也新增「宇宙星野」方案。升级原文件夹后请退出并重新启动 Materia。制作自己的主题参见 [GRAPH_THEME_API.md](GRAPH_THEME_API.md)，旧主题包保持兼容。


## v1.5.0 功能整合

整合研究画布、按材料选择对比、星图形态与北航蓝主题，并保留点击触发的翻译、译文页内批注、生词本及 AI 连接检测。研究画布与材料选择分别保存，切换文献库或关闭程序会等待其保存。翻译仍必须主动点击，不会因选中整页自动发送请求。

本地使用固定的 `Materia-win32-x64` 程序文件夹和已有快捷方式更新，文献库与 AI 配置保留原处。研究画布详见 [RESEARCH_CANVAS.md](RESEARCH_CANVAS.md)，按材料对比详见 [MATERIAL_COMPARISON.md](MATERIAL_COMPARISON.md)。

## PDF 翻译与生词本

划词后先点击「翻译」才会发送请求，选中整页也不会自动调用 AI；旧的自动翻译设置不再触发请求。「添加批注」固定显示，译文出现后即可点击：一键把译文贴到选文附近并保存，支持拖动、缩放和编辑，原文与完整译文保留在详细批注中。

内置阅读器支持点击触发的划词翻译、左侧 PDF / 右侧译文对照、当前页或整篇翻译及停止。译文沿用 AI 服务配置，默认中文，可切换目标语言。生词本可保存词义、原句、出处和学习状态，支持搜索、编辑和 Markdown 导出，完整备份包含生词与译文。扫描页需先 OCR。详见 [TRANSLATION.md](TRANSLATION.md)。

## AI 研究助手

服务设置提供「测试连接」，仅查询模型列表，并显示是否附带密钥和认证结果；检测不会保存输入或发送文献。设置页也会显示实际运行版本，升级时需先关闭旧程序。

服务设置会明确显示密钥是否已载入及是否仅本次有效。未记住密钥时，重启后需重新填写；官方 DeepSeek / OpenAI 服务缺少密钥会先提示，避免空密钥请求。

聊天会自动保存在本机，可从「历史记录」搜索、查看、继续或删除。历史按文献库隔离，重新打开程序后仍保留。

新增文献库研究助手：从左侧「✧」打开，配置 OpenAI 兼容 API 地址、模型和密钥，即可检索文献、梳理笔记、比较原始性能参数并点击引用返回文献。支持全库或选中文献、Chat Completions / Responses 协议、多轮对话及停止生成。AI 功能需要连接你配置的服务；原有文献管理仍可离线使用。详见 [AI_AGENT.md](AI_AGENT.md)。

双击 `release/v1.5.0/Materia-win32-x64/Materia.exe` 或使用顶层 materia 文件夹中的「Materia.exe - 快捷方式」启动，无需安装 Node.js 或启动服务器。移动程序时请保留整个 `Materia-win32-x64` 文件夹。

## 本地文献库

首次正常启动在 EXE 旁建立「文献库」文件夹。通过「备份与设置 → 选择 / 新建文献库」可更换位置；切换时原文件夹保留。

```text
文献库/
  library.json                    标题、作者机构、标签、收藏夹、多条笔记、期刊指标
  papers/                         原始 PDF，以内容指纹命名
  backups/library.previous.json   上一次成功写入的目录数据
  .trash/                         移除文献的恢复记录；原始 PDF 保留
```

PDF 文件在本地保存和显示。主动使用翻译时，选文或待翻译页的文字会发送至已配置的 AI 服务；不自动分析文献或生成标签。相同 PDF 按 SHA-256 去重。目录通过临时文件替换保存，并保留上一份成功数据。完整备份包含活动文献的 PDF、作者机构、笔记、收藏夹、年度期刊指标、生词本和译文缓存。也可以在程序关闭后复制整个文献库文件夹。

程序不附带示范文献、示范数据或示范收藏夹。升级时移除旧版内置示范及开发测试文献，依据明确标识和两份合成测试 PDF 的内容指纹识别，不按标题或标签批量删除真实文献。

## 精简后的操作入口

- 左下角齿轮统一打开「主题与字体」「文献库与备份」「使用指南」「快捷键」；侧栏保留常用导航。
- 勾选文献后才显示上下文工具栏：「对比与作图」直接进入研究流程，「整理所选」集中标签、收藏夹、移除和清空选择。星标、收藏夹归类与移除文献保留独立含义。
- 星图标题右侧保留添加关联和筛选设置；「视图选项」集中局部关系、文献详情、统计概览及隐藏 / 恢复。文献详情的「文献操作」提供编辑、对比选择、另存 PDF 与移除；阅读 PDF 保持直接入口。
- 阅读器底部统一翻页与跳转；顶部缩放百分比菜单提供适宽、整页和系统阅读器。笔记编辑区「笔记操作」提供保存并新建、重新定位、转为整篇笔记和丢弃草稿。
- 科研绘图保留 PNG 快速导出；「更多导出」提供 SVG、当前图数据 CSV、逐篇参与清单及完整测量 CSV。补选文献集中在「已选择文献」折叠区。
- AI 助手沿用统一的线性 SVG 图标；「对话操作」菜单集中历史记录与服务设置，新对话和发送保持直接入口。

菜单支持方向键、Home / End、Enter、Esc 和点击外部关闭，弹出位置会适应窗口边界。保留文献条目右键、阅读器右键平移及已有快捷键。

## 批量 PDF + Markdown 导入

1. 点击「批量导入」，多选 PDF、拖入一批文件，或从文件夹添加。
2. 下载按当前 PDF 文件名生成的 Markdown 模板，交给其他 AI 填写。一份 MD 可描述多篇文献，也可导入多份 MD。
3. 加入 MD 文件或直接粘贴内容，先预览文件匹配、标题、标签和性能记录，再确认保存。

支持只导入 PDF 后再补 MD，也支持仅用 MD 更新已有文献。重复 PDF 不重复保存；同内容但改名的 PDF 可更新元数据。标签采用追加、笔记去重追加；非空性能表替换该篇已有性能记录，空白字段与空表保留已有信息。未匹配或重名歧义会提示。

## 批量移除与撤销

切换到「文献列表」，勾选多篇文献，或点击「全选当前筛选结果」。选中集合可用于性能对比，也可点击「整理所选 → 移除选中文献」；全选包含当前筛选命中的全部文献，不限于列表已展开的前 100 篇。确认窗口列出标题、数量，并提示是否包含当前筛选结果之外的已选文献。

移除以一批提交，原始 PDF、完整文献信息、性能参数和文献笔记保留在本地恢复记录中。页面上方的「撤销上次移除」可恢复这一批，关闭程序再打开仍可撤销。其他文献、标签笔记和期刊指标不受影响。撤销遇到同 ID 的现有文献时保留现有版本。

## 收藏夹与文献快捷操作

文献详情中直接点击「加入收藏夹 / 更改收藏夹」，选择已有主题即可归入；也可「新建收藏夹并加入」。多选文献后，选中后在上下文工具栏点击「整理所选 → 归入 / 移出收藏夹」，左侧收藏夹标题旁的加号也会提供创建并加入所选文献的选项。每篇文献当前归入一个主题收藏夹，移动到其他收藏夹会更新归属；左侧篇数和当前列表立即更新，重启保留。

星形按钮加入的是「我的收藏 · 星标」，与主题收藏夹独立：文献可以同时有星标和一个主题收藏夹。「移出收藏夹」只清除归属，文献、原始 PDF、性能参数和笔记均保留在全部文献中。

在「全部文献 / 文献列表」条目上右键，或点击条目右侧「···」，可阅读 PDF、直接选择收藏夹或新建并加入、添加 / 取消星标、编辑文献信息与标签、加入 / 移出作图选择，以及移除文献。「更多」中提供笔记、复制标题 / DOI。多选时右键其中一篇，对适合批量的操作使用整个选中集合；右键未勾选条目只操作该篇，菜单顶部显示范围。缺少 PDF 或 DOI 的操作会禁用。

菜单支持方向键、Enter、Esc，聚焦文献条目后可按 Shift+F10 打开；点击外部关闭。移除仍需确认并可撤销，与「移出收藏夹」分开。阅读器中的右键继续用于平移页面，输入框保留原生菜单。

## 材料与性能参数对比作图

一篇文献可以附带多个材料，各材料独立保存名称、成分 / 配方、说明及性能参数。文献详情中「管理材料 / 参数」可添加、重命名或移除材料，并分别增删性能记录；未点击保存时取消可保留原数据。材料可以暂不填写参数。每条参数仍分别记录样品 / 批次、名称、数值、单位、条件、来源、限定符及误差。

点击顶部「性能参数」或左侧尺子图标，先在全库参数目录中搜索参数名称或单位。点击参数名称立即列出录入该参数的全部文献，单篇参数、不同单位和暂时无法绘图的记录均保留；不受标签篇数、之前选中集合、星图隐藏节点或原筛选条件影响。结果直接展示数值、单位、样品、条件和来源，可用标题搜索，再逐篇勾选或全选，点击「用所选文献作图」。也可从详情参数名、对照表参数名跳回全库结果。

左侧折线图图标是主要作图入口；无选择时先显示全库参数入口，有选择时进入绘图。同一窗口可切换「参数对照表 / 科研绘图」。

- 参数对照表：按参数名称与单位分行，每列一篇文献，列按年份排列；每个值保留样品、条件与来源。
- 折线图 / 散点图：横纵坐标均可选择年份、IF 或性能参数，坐标参数可搜索；按测试条件、文献、材料、样品或期刊分组。
- 柱状对比：每条原始观测独立一柱，不平均，未填写发表年份也能比较。
- 高级绘图设置：对数轴、坐标范围、原始 X/Y 误差棒、参考线、数值标签和画布尺寸；设置保存在当前本地文献库。
- 导出高分辨率 PNG、SVG 矢量图、与当前图完全一致的数据 CSV、逐篇参与清单，以及全部测量记录 CSV。

不同单位不自动换算或混合。参数与参数在同文献、同材料、同样品中配对，优先匹配相同条件；多值歧义会跳过并逐篇解释，不做平均。默认不把约数 / 界限值画入曲线，可主动勾选包含。缺少年份、配对参数、单位不匹配、无效数值、条件不匹配、对数轴非正值及范围排除均列入参与清单，选中文献不会静默消失。折线只连接原始观测点，不拟合、不推断演进规律。误差棒使用录入的原始 ± 误差，对数轴无法容纳的误差区间会单独提示。

## 笔记与双向链接

- 点击文献标题或「管理 / 添加」：为同一篇文献保留多条独立笔记。
- 点击标签或左侧「标签与笔记」：查看关联标题，为标签保留多条笔记。
- 笔记中使用 `[[完整文献标题]]` 或 `[[#标签名称]]` 跳转，目标面板会显示反向链接。
- 桌面版修改标题时，会同步更新笔记中的标题链接。

## 内置 PDF 阅读与图文批注

点击文献详情的「阅读 PDF 与批注」，在程序内阅读本地 PDF。支持单页、双页并排、双页且封面独立，提供适合宽度、整页显示、放大缩小和文字选择复制。双页模式会先收起笔记区，点击标记或新建笔记再展开；也可通过右上角按钮随时展开 / 收起，并拖动分隔线调整笔记宽度。阅读页码、缩放、排列、侧栏宽度与滚轮习惯会保留。

底部统一提供翻页、页码跳转与进度条；双页一次翻一组，文末奇数页和独立封面会正确处理。底部进度条可拖动跳转。左右方向键翻一页 / 一组，空格 / PageDown 向下阅读一屏，Shift+空格 / PageUp 向上阅读一屏，到页底 / 页顶后继续翻组；Home / End 到文首 / 文末。底部翻页设置图标可开启滚轮到边界后翻页，默认关闭。输入笔记时不会触发阅读快捷键。

按住鼠标右键拖动可上下、左右平移页面，放大或双页阅读时也可使用。右键平移不创建标记，也不触发翻页。

顶部提供三种标注工具：区域（R）拖出矩形；文字（T）在页面点击或框选后写入文字；箭头（A）从起点拖到目标位置，可附上文字说明。阅读 / 选字（V）可恢复文字选择。双页中的左右页独立记录坐标。标注提供暖黄、青绿、海蓝、玫瑰四种颜色，文字与箭头说明可调整字号。文字浮动编辑框支持 Ctrl+Enter 保存。

点击页面标注会出现操作条；双击或点击「编辑文字」修改页内文字，点击「添加详细批注」在右侧继续解释，并上传或粘贴图片。**页内文字与详细批注分别保存**，可为同一条标注保留简短提示和完整分析。选中后拖动文字框 / 区域可移动，右下角控制点可调整尺寸；拖动箭头线段可整体移动，拖动起点 / 终点控制点可改变指向，拖动箭头文字可移动起点。调整后点击保存或按 Ctrl+S。

原有区域标记继续支持；可以只保存标记，也可以只保存图片。「新笔记」不关联页面位置。再次选择标注工具会新建下一条批注；编辑已有批注时可在「位置与草稿」中重新定位或改为整篇文献笔记，转换时保留页内文字。

笔记区分为列表与编辑两页，编辑区提供完整高度、字数提示、选中文字摘录、图片粘贴、Ctrl / Command+S 正式保存，以及「保存并新建」。停止输入约一秒后自动保存本地草稿；切换到其他笔记、关闭阅读器时会先保存当前草稿，再继续操作。草稿与正式笔记分开，重新打开可在列表继续编辑；原笔记在别处更新过时，会把旧草稿作为新笔记恢复，避免覆盖。草稿保存在当前文献库的 `readerDrafts` 设置，**只有正式保存后才计入文献笔记与完整备份**；可在「位置与草稿」中丢弃草稿。

页面标记、普通文献笔记共用原有笔记集合。阅读器可按全部 / 当前页 / 整篇筛选，支持搜索页内文字、详细批注及图片名。点击笔记页码会跳到相应页和区域。原笔记管理窗口、文献详情预览、全库笔记搜索、标题 / 标签双向链接继续使用，并能显示页内文字、图片或跳回标记。

每条笔记最多 6 张图片，支持 PNG / JPEG / WebP / GIF / BMP 上传及图片粘贴。图片最长边缩至 1600px，压缩后每张不超过约 1 MB；GIF 作为静态图片保存。点击缩略图查看大图。图片和位置数据随笔记保存在本地 `library.json`，完整备份、恢复及批量移除 / 撤销均包含它们。

标记使用页面比例坐标，随阅读缩放对齐；更换为不同 PDF 时，旧标记保留并提示重新定位，不套到新文件上。原始 PDF 不改写，「另存 PDF」导出原文件，标记与批注通过文献库或完整备份迁移。无法显示的 PDF 可从阅读器右上角打开系统阅读器；密码 PDF 可在本地解锁阅读，密码不保存。

渲染组件使用离线内置的 [Mozilla PDF.js](https://mozilla.github.io/pdf.js/examples/)，版本与 Apache-2.0 许可证位于 `dist/vendor/pdfjs/`。不依赖外部 CDN。

升级已有程序后，请完全退出并重新启动 Materia.exe，以加载新的本地标注存储支持。原有文献库与笔记保持兼容。

## 主题切换与 CSS 导入

左侧调色盘图标或「文献库与备份 → 主题与外观」提供学术纸白、深海蓝、石墨夜读、暖砂手稿、学术紫、维基百科。维基百科采用白底、蓝色链接、衬线标题和细灰边线。可分别选择界面 / 正文和标题字体，实时预览；字体选择在切换主题时保留，也可恢复跟随主题。使用本机已安装字体，缺少字体时自动使用后备字体，不更改 PDF 原文或科研图导出字体。

在左下角齿轮 →「主题与字体」中，拖动「界面字号」滑块可在 85%–150% 之间调整菜单、文献列表、笔记和 AI 聊天的文字。拖动即时预览，松开保存；「恢复默认字号」回到 100%。字号随当前文献库保存，重启及切换主题后保留，PDF 原文、图谱节点标题和科研图导出沿用各自字号。

可批量导入 `.css` 变量主题、导出当前主题（包含生效字体）、下载模板、删除自定义主题及恢复默认。选择、字体、字号与主题保存在当前本地文献库，重启恢复。

支持配色、字体和圆角变量，普通选择器及布局规则暂不支持。详见 `THEMES.md` 与 `theme-template.css`；科研图导出保持白底。

## 搜索、排序与过滤

星图默认仅显示文献节点，没有连线，也没有自动标签、年份或机构节点。点击画布标题右侧的加号「添加关联节点」，从已录入的真实标签、年份、作者或作者机构中手动加入节点，才会连接匹配文献。可加入多个不同类型，同类型同值去重；手动关联节点允许仅匹配一篇文献，筛选后匹配为零时也保留节点。作者与机构必须已录入结构化信息，不根据标题推测。

文献与关联节点均可拖动，拖动时连线和相邻节点响应，松开后自然回落；按住 Shift 拖动可固定位置，双击或聚焦后按 P 释放。位置与固定状态保存至当前文献库。点击关联节点查看实际匹配文献；右键移除该关联节点，或在加号窗口清空关联节点，画布随即恢复无连线。移除不会修改原文献、标签或作者信息。右键文献或点击左侧眼睛图标可隐藏当前文献，通过「恢复隐藏」或清除筛选恢复。

默认使用画布为主的紧凑布局。左侧细图标栏统一放置导入、参数目录、作图、对照表、批量标签 / 收藏夹和批量移除；悬停提示名称，键盘可聚焦。左右面板可独立收起。画布标题与按钮占用独立行，避免覆盖节点。标题随缩放渐进显示并进行文字防碰撞，悬停或选中优先显示名称与真实关联。

布局使用本地打包的 D3 力导向模拟：真实关联连线产生牵引，全图节点相互排斥，弱中心力约束整体分布。拖住节点时持续运行，关联节点随牵引重新排布；松手后逐渐收敛到新的平衡位置。不会记录拖动前的锚点或强制整体回原位，也不会增加文献关系。齿轮「关系图设置 → 力学布局 → 运动惯性」调整阻尼，默认 0.5；旧版回弹程度自动停用。「释放全部固定」可一次解除包括隐藏节点在内的历史固定位置，随后继续布局。Shift 拖动仍可固定节点；已固定节点不会被布局推走。暂停时可调整单个节点；系统开启减少动画时采用静态布局更新。

画布坐标会适应实际宽高，底部「适应全部可见节点」或快捷键 0 会连同远处固定节点一起纳入视野。齿轮中的「重新布局」重新排列未固定节点，保留固定位置；需要重新移动固定节点时，可双击或按 P 释放。图谱采用接近 Obsidian 的小圆点、细直线、简洁底色和随缩放淡入的标题，悬停或选中时突出直接关系，不增加装饰光晕或任何文献关联。英文标题按单词换行，标签位置尽量保持稳定并避免互相覆盖。

齿轮「关系图设置」按需展开：筛选与局部关系、颜色分组、显示与文字、力学布局。可切换全局 / 当前文献的局部关系及 0 / 1 / 2 层深度，并调整中心力、排斥力、连接力与距离；暂停或重新布局也在这里。最多显示当前筛选的 350 篇文献、100 个手动关联节点；列表仍可访问全部文献。

列表勾选多篇后，「整理所选 → 批量标签与收藏夹」可追加标签、移除指定标签、替换全部标签（留空可清空），以及归入现有收藏夹、新建收藏夹或移出收藏夹。确认前展示每篇文献的标签和收藏夹前后变化；保存时整批提交，文献笔记、作者、性能参数和原始 PDF 保留。

搜索可限定标题、标签或笔记。「全部」还覆盖作者、机构、期刊和 DOI。笔记搜索包括文献自身及关联标签的笔记。`#关键词` 限定标签，多词同时匹配。

过滤同时作用于星图和列表：多标签（全部 / 任一）、期刊、收藏夹、作者、机构、年份或范围、IF 指标年份、IF 范围、收藏、含笔记、库内有关联。支持开关连线及标题。星图最多显示过滤结果的前 350 篇，全部文献仍可在列表中访问。

常规标签筛选、标签目录和标签统计仍要求在整个文献库中关联至少 3 篇不同文献。不足 3 篇的标签与笔记保留，可搜索和编辑。手动添加关联节点、全库性能参数检索独立于该门槛。

排序支持最近添加、发表年份、标题及影响因子升降序；没有 IF 的文献始终排在 IF 排序末尾。

文献详情中的关联文献分成「作者 / 机构关联」和「Tag 关联」两组。前者展示共同作者、共同机构的具体名称，共同作者优先，再按共同作者和机构数量排序；作者与机构匹配忽略大小写、全角字符及多余空格，依据已录入名称判断。Tag 组按不同共享标签的数量降序，同分时最近添加的文献靠前，并显示重合数量及标签。只在两篇文献中使用的 Tag 也可参与详情关联，不受星图的三篇门槛限制。每组先显示前三篇，其余可展开；同一文献可同时出现在两组，点击即可查看详情。

## 全部作者、机构与期刊指标

每行填写一位作者，格式 `姓名 | 机构一；机构二`。支持全部作者与每位作者的多家机构，也可导入其他 AI 整理的 Markdown；旧版 JSON 仍兼容。

期刊指标支持 CSV、TSV 和 JSON，需要期刊名、IF 数值与指标年份，可附来源。各年份分别保留，同期刊同年份更新。未录入的指标显示「未填写」，不会自动生成或抓取 IF。

随程序提供 `journal-metrics-2025.csv`，包含 2026-10-27 从出版方公开页面核验的 17 本期刊的 2025 年两年期 JIF，包括 JMST、Materials Research Letters、Nature Communications、NPG Asia Materials 等。启动时自动补入当前文献库；相同期刊和年份已有用户数据时保留用户数据。通过「文献库与备份 → 期刊影响因子 → 查看数据 / 来源」查看数值、指标年份和原始来源，也可导出 CSV 或继续导入其他期刊。此数据为公开期刊指标的有限摘录，不是完整 JCR 数据库，未覆盖期刊仍显示「未填写」。

默认优先使用文献手动指定的 IF，否则匹配该期刊最新导入年份。「指标年份」过滤器可指定同一年比较，数值旁显示对应年份。

详细 Markdown 规范见 `DATA_IMPORT.md`，EXE 同目录提供 `metadata-template.md`；程序内可下载包含当前 PDF 文件名的专属模板。也保留旧版 JSON 与期刊指标 CSV 模板。新版 MD 模板采用版本 2：文献下先列出多个材料，再分别填写性能表；仍兼容版本 1，旧性能记录按样品归入材料，未命名样品归入「未命名材料」。完整备份包含全部材料及性能参数，旧网页数据可备份后在 EXE 中恢复。

## 开发

```sh
npm install
npm start          # 桌面程序
npm run preview    # 网页预览，使用浏览器存储
npm test
npm run check
npm run verify:ui  # 独立无头浏览器验证，不操作已打开的窗口
npm run build:exe  # 生成 Windows x64 程序文件夹
```

`desktop/` 负责文件夹存储和桌面接口，`dist/` 负责界面。打包使用独立暂存目录，不包含个人文献、测试数据或凭据；已有发行目录会保留，防止重打包覆盖用户文献。
