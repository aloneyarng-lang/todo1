# Materia · 材料文献星图（Windows 桌面版）

双击 `release/v1.2.0/Materia-win32-x64/Materia.exe` 启动，无需安装 Node.js 或启动服务器。移动程序时请保留整个 `Materia-win32-x64` 文件夹。

## 本地文献库

首次正常启动在 EXE 旁建立「文献库」文件夹。通过「备份与设置 → 选择 / 新建文献库」可更换位置；切换时原文件夹保留。

```text
文献库/
  library.json                    标题、作者机构、标签、收藏夹、多条笔记、期刊指标
  papers/                         原始 PDF，以内容指纹命名
  backups/library.previous.json   上一次成功写入的目录数据
  .trash/                         移除文献的恢复记录；原始 PDF 保留
```

不解析或上传文献内容。相同 PDF 按 SHA-256 去重。目录通过临时文件替换保存，并保留上一份成功数据。完整备份包含活动文献的 PDF、作者机构、笔记、收藏夹与年度期刊指标。也可以在程序关闭后复制整个文献库文件夹。

程序不附带示范文献、示范数据或示范收藏夹。升级时移除旧版内置示范及开发测试文献，依据明确标识和两份合成测试 PDF 的内容指纹识别，不按标题或标签批量删除真实文献。

## 批量 PDF + Markdown 导入

1. 点击「批量导入」，多选 PDF、拖入一批文件，或从文件夹添加。
2. 下载按当前 PDF 文件名生成的 Markdown 模板，交给其他 AI 填写。一份 MD 可描述多篇文献，也可导入多份 MD。
3. 加入 MD 文件或直接粘贴内容，先预览文件匹配、标题、标签和性能记录，再确认保存。

支持只导入 PDF 后再补 MD，也支持仅用 MD 更新已有文献。重复 PDF 不重复保存；同内容但改名的 PDF 可更新元数据。标签采用追加、笔记去重追加；非空性能表替换该篇已有性能记录，空白字段与空表保留已有信息。未匹配或重名歧义会提示。

## 批量移除与撤销

切换到「文献列表」，勾选多篇文献，或点击「全选当前筛选结果」。选中集合可用于性能对比，也可点击「批量移除」；全选包含当前筛选命中的全部文献，不限于列表已展开的前 100 篇。确认窗口列出标题、数量，并提示是否包含当前筛选结果之外的已选文献。

移除以一批提交，原始 PDF、完整文献信息、性能参数和文献笔记保留在本地恢复记录中。页面上方的「撤销上次移除」可恢复这一批，关闭程序再打开仍可撤销。其他文献、标签笔记和期刊指标不受影响。撤销遇到同 ID 的现有文献时保留现有版本。

## 性能参数对比与作图

性能记录分别保存：样品、参数名称、数值、单位、测试条件、来源，以及可选限定符和误差。名称和数值是独立字段，数值存为数值类型。文献详情中「管理 / 编辑」可逐条增删修改。

点击顶部「性能参数」或左侧尺子图标，先在全库参数目录中搜索参数名称或单位。点击参数名称立即列出录入该参数的全部文献，单篇参数、不同单位和暂时无法绘图的记录均保留；不受标签篇数、之前选中集合、星图隐藏节点或原筛选条件影响。结果直接展示数值、单位、样品、条件和来源，可用标题搜索，再逐篇勾选或全选，点击「用所选文献作图」。也可从详情参数名、对照表参数名跳回全库结果。

左侧折线图图标是主要作图入口；无选择时先显示全库参数入口，有选择时进入绘图。表格图标提供参数对照表。

- 参数对照表：按参数名称与单位分行，每列一篇文献，列按年份排列；每个值保留样品、条件与来源。
- 折线图 / 散点图：横纵坐标均可选择年份、IF 或性能参数，坐标参数可搜索；按测试条件、文献、样品或期刊分组。
- 柱状对比：每条原始观测独立一柱，不平均，未填写发表年份也能比较。
- 高级绘图设置：对数轴、坐标范围、原始 X/Y 误差棒、参考线、数值标签和画布尺寸；设置保存在当前本地文献库。
- 导出高分辨率 PNG、SVG 矢量图、与当前图完全一致的数据 CSV、逐篇参与清单，以及全部测量记录 CSV。

不同单位不自动换算或混合。参数与参数在同文献、同样品中配对，优先匹配相同条件；多值歧义会跳过并逐篇解释，不做平均。默认不把约数 / 界限值画入曲线，可主动勾选包含。缺少年份、配对参数、单位不匹配、无效数值、条件不匹配、对数轴非正值及范围排除均列入参与清单，选中文献不会静默消失。折线只连接原始观测点，不拟合、不推断演进规律。误差棒使用录入的原始 ± 误差，对数轴无法容纳的误差区间会单独提示。

## 笔记与双向链接

- 点击文献标题或「管理 / 添加」：为同一篇文献保留多条独立笔记。
- 点击标签或左侧「标签与笔记」：查看关联标题，为标签保留多条笔记。
- 笔记中使用 `[[完整文献标题]]` 或 `[[#标签名称]]` 跳转，目标面板会显示反向链接。
- 桌面版修改标题时，会同步更新笔记中的标题链接。

## 搜索、排序与过滤

星图默认仅显示文献节点，没有连线，也没有自动标签、年份或机构节点。点击画布标题右侧的加号「添加关联节点」，从已录入的真实标签、年份、作者或作者机构中手动加入节点，才会连接匹配文献。可加入多个不同类型，同类型同值去重；手动关联节点允许仅匹配一篇文献，筛选后匹配为零时也保留节点。作者与机构必须已录入结构化信息，不根据标题推测。

文献与关联节点均可拖动，拖动时连线和相邻节点响应，松开后固定；双击或聚焦后按 P 释放。位置与固定状态保存至当前文献库。点击关联节点查看实际匹配文献；右键移除该关联节点，或在加号窗口清空关联节点，画布随即恢复无连线。移除不会修改原文献、标签或作者信息。右键文献或点击左侧眼睛图标可隐藏当前文献，通过「恢复隐藏」或清除筛选恢复。

默认使用画布为主的紧凑布局。左侧细图标栏统一放置导入、参数目录、作图、对照表、批量标签 / 分组和批量移除；悬停提示名称，键盘可聚焦。左右面板可独立收起。画布标题与按钮占用独立行，避免覆盖节点。标题随缩放渐进显示并进行文字防碰撞，悬停或选中优先显示名称与真实关联。

齿轮「关系图设置」按需展开：筛选与局部关系、颜色分组、显示与文字、力学布局。可切换全局 / 当前文献的局部关系及 0 / 1 / 2 层深度，并调整中心力、排斥力、连接力与距离；暂停或重新布局也在这里。最多显示当前筛选的 350 篇文献、100 个手动关联节点；列表仍可访问全部文献。

列表勾选多篇后，「批量标签 / 分组」可追加标签、移除指定标签、替换全部标签（留空可清空），以及移入现有分组、新建分组或移出分组。确认前展示每篇文献的标签和分组前后变化；保存时整批提交，文献笔记、作者、性能参数和原始 PDF 保留。

搜索可限定标题、标签或笔记。「全部」还覆盖作者、机构、期刊和 DOI。笔记搜索包括文献自身及关联标签的笔记。`#关键词` 限定标签，多词同时匹配。

过滤同时作用于星图和列表：多标签（全部 / 任一）、期刊、收藏夹、作者、机构、年份或范围、IF 指标年份、IF 范围、收藏、含笔记、库内有关联。支持开关连线及标题。星图最多显示过滤结果的前 350 篇，全部文献仍可在列表中访问。

常规标签筛选、标签目录和标签统计仍要求在整个文献库中关联至少 3 篇不同文献。不足 3 篇的标签与笔记保留，可搜索和编辑。手动添加关联节点、全库性能参数检索独立于该门槛。

排序支持最近添加、发表年份、标题及影响因子升降序；没有 IF 的文献始终排在 IF 排序末尾。

## 全部作者、机构与期刊指标

每行填写一位作者，格式 `姓名 | 机构一；机构二`。支持全部作者与每位作者的多家机构，也可导入其他 AI 整理的 Markdown；旧版 JSON 仍兼容。

期刊指标支持 CSV、TSV 和 JSON，需要期刊名、IF 数值与指标年份，可附来源。各年份分别保留，同期刊同年份更新。未录入的指标显示「未填写」，不会自动生成或抓取 IF。

随程序提供 `journal-metrics-2025.csv`，包含 2026-10-27 从出版方公开页面核验的 17 本期刊的 2025 年两年期 JIF，包括 JMST、Materials Research Letters、Nature Communications、NPG Asia Materials 等。启动时自动补入当前文献库；相同期刊和年份已有用户数据时保留用户数据。通过「文献库与备份 → 期刊影响因子 → 查看数据 / 来源」查看数值、指标年份和原始来源，也可导出 CSV 或继续导入其他期刊。此数据为公开期刊指标的有限摘录，不是完整 JCR 数据库，未覆盖期刊仍显示「未填写」。

默认优先使用文献手动指定的 IF，否则匹配该期刊最新导入年份。「指标年份」过滤器可指定同一年比较，数值旁显示对应年份。

详细 Markdown 规范见 `DATA_IMPORT.md`，EXE 同目录提供 `metadata-template.md`；程序内可下载包含当前 PDF 文件名的专属模板。也保留旧版 JSON 与期刊指标 CSV 模板。完整备份包含全部性能参数，旧网页数据可备份后在 EXE 中恢复。

## 开发

```sh
npm install
npm start          # 桌面程序
npm run preview    # 网页预览，使用浏览器存储
npm test
npm run check
npm run verify:ui  # 独立无头浏览器验证，不操作已打开的窗口
npm run build:exe  # 生成 Windows x64 程序文件夹
```

`desktop/` 负责文件夹存储和桌面接口，`dist/` 负责界面。打包使用独立暂存目录，不包含个人文献、测试数据或凭据；已有发行目录会保留，防止重打包覆盖用户文献。
