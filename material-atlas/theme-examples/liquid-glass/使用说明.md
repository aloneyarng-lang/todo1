# 澄璃 · Liquid Glass

液态玻璃和 Apple 字体现已直接内置到软件。重启后，在「主题与字体」点击「液态玻璃 · 浅色 / 深色」即可使用；下方可单独选择 SF Pro、SF Mono、New York 等字体。本目录 JSON 仅保留为旧版示例，无需再导入。中文使用本机苹方或内置思源黑体，详见软件的 `dist/fonts/README.md`。

为 Materia 制作的 macOS 灵感玻璃主题，Clear v2。背景保持中性纯色：浅色为银灰，深色为石墨灰。低填色的透明玻璃、薄亮边和局部反光形成层次；颜色重点用于蓝色主按钮与选中状态。

## 导入

1. 退出并重新打开本文件夹中的 Materia 桌面程序，让最新的玻璃与按压交互支持生效。
2. 点击左下角齿轮 →「主题与字体」→「导入主题包 / CSS」。
3. 选择 `01-澄璃-浅色.mtheme.json` 或 `02-澄璃-深色.mtheme.json`。
4. 预览满意后，点击「应用并保存主题」。两个文件也可同时导入，再分别切换。

已经导入旧版时，重新导入同名文件会更新现有主题，不必先删除。

字体效果建议在「字体与字号」中选择「恢复跟随主题」；已有的个人字体覆盖会优先于主题字体。星图设置中的「星图形态」选择「跟随主题包」，即可使用主题的通透圆环和柔和曲线。

## 包含的设计

- 背景独立使用 `tokens.--paper` 的纯色，不固定在玻璃材质里，后续可单独更换。
- 主容器填色约 12%（浅色）/18%（深色），轻量模糊、薄亮边和局部高光，减少叠加的雾白底层。
- 按钮按下快速收缩，松手阻尼回弹；鼠标和空格/回车键都支持，悬停反光跟随指针。
- 20px 圆角面板、胶囊控件、分段式视图切换与通透搜索框。
- 11 个自定义细线图标，覆盖文献库、文件夹、星图、助手、设置、绘图等入口。
- macOS 使用系统字体栈；Windows 自动使用 Segoe UI 与微软雅黑，无需下载字体。
- 星图使用蓝色空心圆环、暖色关联圆环和轻量曲线。
- 深浅色分别保存，切换后随当前文献库持久保留。

`03` 至 `06` 开头的 PNG 为实际桌面程序的界面截图，截图使用独立的演示文献库。

## 兼容与资源

主题格式为 `materia-theme` / `schemaVersion: 2`，使用新增的 `ui.style: "glass"`。本工作区桌面快捷方式指向的程序已补充支持；其他电脑上的旧版 Materia 需先升级玻璃渲染功能。不要把 `glass` 改成其他样式来开启玻璃效果。

每个 JSON 均为约 8 KB 的独立主题包，不依赖外网、图片或额外字体。完整主题包导出会保留材质；「仅导出 CSS 变量」不会包含玻璃效果。系统要求减少透明度时采用实色面板；不支持背景模糊的浏览器也采用实色回退。启用「减少动态效果」时保留按压明暗变化，关闭缩放与回弹。按压反馈为界面动画，物理震动取决于设备硬件。PDF 原文与科研图本身的配色不属于界面主题。

## 重新制作

在 Materia 源码目录运行：

```sh
node theme-examples/liquid-glass/build.mjs
```

`build.mjs` 包含两套配色、排版、图标和星图设计，通过程序的公开主题校验器生成两个 JSON 文件。

初版渲染支持更新前的资源保存在 `material-atlas/.local/liquid-glass-upgrade-backup/`；Clear v2 更新前的材质与运行时文件保存在 `material-atlas/.local/liquid-glass-v2-backup/`。需要回到初版时，先切换到其他主题，再将 v2 备份中的 `theme-runtime.js` 与 `theme-appearance.css` 复制回 `release/v1.3.0/Materia-win32-x64/resources/app/dist/`。
