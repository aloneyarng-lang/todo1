# 远星航图 · Deepfield

为 Materia 星图接口 v2 制作的独立宇宙主题。程序已在原 materia 文件夹内升级，主题成品独立放在桌面。

## 导入

1. 完全退出并重新打开 Materia，让升级后的界面与本地接口一起生效。
2. 左下角齿轮 →「主题与字体」→「导入主题包 / CSS」，选择本文件夹的「01-远星航图.mtheme.json」。
3. 预览后点击「应用并保存主题」。
4. 星图设置 →「星图形态」选择「跟随主题包」。字体如有个人覆盖，可选择「恢复跟随主题」。

文献节点呈现冷白恒星，包含细长光芒、明亮内核和柔和光晕；实际关联节点呈现暖金带环行星，光环有倾角与前后遮挡；背景含蓝紫/青色星云及远景星野。存在的关系以星座式连线呈现。背景小星是装饰，不代表文献。

若当前星图没有关联节点，请用原有「添加关联」选择真实标签、年份等，再开启关联节点与连线。主题不会凭空增加文献关系。拖动、缩放、固定节点、阅读与文献管理沿用原操作。

「暂停布局」同时暂停远景星的缓慢闪烁；系统开启减少动态效果时不闪烁。星野最多 520 颗装饰星；没有背景动画循环驱动文献力学。

## 以后制作新主题

复制 JSON 并修改 name、tokens 和 graph，即可通过相同导入入口使用新主题，无需再次修改程序。可独立配置恒星/行星形态、星野密度与颜色、双色星云及浓度、光环尺寸与角度、辉光、种子及闪烁。详见随附「星图主题接口-v2.md」。旧主题包继续可导入。

CSS 精简版不携带完整 UI、定制图标及字体文件。完整 JSON 自包含，不依赖网络、图片或插件脚本。Source Code Pro 字体未经修改，许可附后。

预览使用合成演示文献，不写入真实文献库。升级不会自动改写你的文献库或应用主题。
