# 命运石之门 · 橙青星芒

已内置到 Materia，在「主题与字体」选择「命运石之门」，支持浅色和深色透明玻璃。

采用 STEINS;GATE RE:BOOT 官网的官方标志、牧濑红莉栖角色图，显示在主题预览和工作区的小型品牌栏内。原图以 PNG 内置，离线可用，导出完整主题包时一并保留。来源及版权见 [SOURCES.md](SOURCES.md)。

星图以用户给定的橙青光点参考为方向：青色文献亮核、橙色关联核心，配同心薄光环、放射光芒和细直线。只连接真实关联；保留纯色背景。已移除旧版重复的数字形文献节点。拖动、选择、右键、自然整理与阅读状态不变。

星图形态选择「跟随主题包」或「主题形态 · 命运石之门」。引用内置 SF Pro、SF Mono 与思源黑体，不复制字体文件。

独立包：`命运石之门-世界线.mtheme.json`。生成与检查：

```powershell
node theme-examples/steins-gate/build.mjs
node scripts/validate-theme-design.mjs theme-examples/steins-gate/命运石之门-世界线.mtheme.json
```
