# 制作主题包时必须遵守

本目录用于 Materia 主题包。开始制作前，阅读同目录的 `DESIGN_RULES.md`，从根目录 `theme-template.mtheme.json` 复制模板。

- 每个主题只制作一个包，必须同时提供 `variants.light` 和 `variants.dark`。
- 所有主题沿用应用内置的透明玻璃、圆角和按压回弹。`ui.style` 必须为 `glass`；不得制作关闭玻璃的开关或用 CSS 改写功能布局。
- 使用纯色背景；不添加壁纸、彩色背景光斑或全屏渐变。
- 字体、图标、星图允许形成主题差异，界面层级、按钮位置、圆角及操作方式保持一致。
- 不把应用内置 Apple 字体文件复制进主题包。引用内置字体名即可；其他嵌入字体必须附上来源和允许嵌入的原始许可。
- 交付前运行 `node scripts/validate-theme-design.mjs <主题路径>`，并在软件中检查明暗两种模式、菜单、阅读器和设置。旧包的兼容导入不代表新包符合制作规范。
