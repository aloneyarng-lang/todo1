# 研究画布：思维导图、关系图与规则生成

从左侧「研究画布」或窄工具栏的关系图标进入。可创建多张独立画布；初次进入不会自动加入示例，点击「从材料研究示例开始」才创建示例内容。

## 图形编辑

- 节点可自由拖动，拖动空白或按右键拖动移动视图；滚轮、右下角按钮缩放，「适应画布」显示全图。
- 「新节点」在视图中心添加独立节点；右侧「添加子节点」连接当前节点和新节点。
- 「连接节点」启用连线模式，依次点起点、终点；选中节点时直接以它作为起点。Esc 退出连线模式。
- 选中节点后可编辑文字、研究笔记、形状、颜色、分组、图片、文献与标签笔记链接。相同分组名自动显示共同的边界。
- 选中连线可编辑关系文字、虚线及箭头。Delete 删除当前节点或连线；删除节点同时删除它的连接，其他节点与文献保留。
- Ctrl+Z 撤销、Ctrl+Shift+Z 或 Ctrl+Y 重做。删除整张画布需要再次点击确认，并可在左侧撤销删除。
- 思维导图支持左右、向右、向左、向下展开；「自动布局」重新排版。自由关系布局允许任意连接，「自动布局」使用整齐网格。

## 规则代码

点击「规则代码」，编辑后点「预览生成」，确认再点「应用到画布」。预览不替换当前图形；错误显示具体行号，草稿与原图分别保存。Ctrl+Enter 预览，Ctrl+Shift+Enter 应用。「还原代码」放弃规则草稿并显示当前图形的规则。

图形编辑会同步更新规则，包含节点坐标。存在未应用的规则草稿时，请先应用或还原，再继续编辑图形，避免两份内容互相覆盖。

可以直接粘贴 AI 输出的单个代码块（语言标记为 `materia-canvas`、`mcanvas` 或 `text`），也可使用纯规则文本。

基本语法：每行一条规则；文字使用 JSON 双引号字符串，可用 `\n` 换行、`\"` 输入引号。空行及以 `//` 或 `#` 开头的行是注释。

```text
canvas "高熵合金研究"
layout mindmap
direction right

node root "强度与塑性协同"
node composition "成分设计"
node process "热处理"
node structure "析出相"
node performance "力学性能"

root -> composition
root -> process
process -> structure : "调控"
structure -> performance : "影响"

style structure shape=hexagon color=purple
note structure "需要进一步确认尺寸与分布。"
group "实验变量" [composition, process]
```

| 规则 | 含义 |
| --- | --- |
| `canvas "名称"` | 画布名，最多一条 |
| `layout mindmap` / `layout free` | 思维导图 / 自由关系 |
| `direction both` / `right` / `left` / `down` | 展开方向 |
| `node id "文字"` | 定义节点，ID 唯一且以字母或下划线开头，可含数字、短横线 |
| `a -> b : "说明"` | 从 a 指向 b，关系文字可省略 |
| `style a shape=hexagon color=purple` | 节点外观 |
| `note a "研究笔记"` | 节点详细说明 |
| `group "实验变量" [a, b]` | 节点分组 |
| `link a paper="文献ID"` | 关联库内文献，点击打开详情 |
| `link a tag="标签名称"` | 关联现有的标签笔记，可打开并添加多条笔记 |
| `image a "asset:图片ID"` | 引用当前画布已有的图片资源 |
| `position a 100 200` | 节点中心坐标，单位为画布坐标 |
| `edge-style a b dashed=true arrow=false` | 连线虚实与箭头 |

形状支持 `roundrect`、`rect`、`ellipse`、`diamond`、`hexagon`。颜色支持 `accent`、`blue`、`purple`、`gold`、`green`、`red`、`gray` 或 `#RRGGBB`。强调色、背景、边线与字体跟随当前主题，切换主题保留布局。

同一方向的两个节点之间只保留一条连线；可添加反向连线或交叉连线。思维导图自动布局会从关系中选取树状骨架来排版，额外关系仍全部显示。节点 ID 不变时，重新生成会保留其手工坐标；新节点自动安排。显式的 `position` 优先。要重新排版，请应用代码后点击「自动布局」。

## 图片、导入与导出

节点图片支持 PNG、JPEG、WebP；上传时压缩到最长边 1280 像素，作为画布内嵌资源保存，移动原文件不影响画布。可拖入图片到已选节点。资源 ID 显示在图片下方，可供规则引用；规则不直接读取任意路径或网络图片。

「导入与导出」支持：

- 完整画布 `.materia-canvas.json`：包含图形、笔记、布局、规则草稿与图片，适合备份和分享。导入创建新副本，不覆盖已有画布。
- 规则文本 `.canvas.md`：可由其他 AI 按上述规范生成并导入，也可直接粘贴。图片资源请使用完整 JSON 包一起传递。
- SVG：矢量节点、文字、连线与内嵌图片，采用当前主题；其他电脑缺少相应字体时使用后备字体。
- PNG：完整画布图片，自动适配导出尺寸，不受当前缩放或可见范围限制。

## 本地保存

桌面版将全部画布写在当前文献库文件夹的 `research-canvases.json`，上一版保存在 `research-canvases.previous.json`。保存采用临时文件原子替换，与文献元数据及 PDF 分开；编辑自动保存，返回文献库和关闭桌面窗口时会等待保存完成。保存失败时保留编辑内容和窗口，可点击「立即保存」重试。

浏览器预览版使用本浏览器本地数据库。迁移请导出完整画布 JSON，或复制整个桌面文献库文件夹；原有的文献 JSON 备份目前不包含独立画布文件。

每张画布最多 300 个节点、700 条连线、24 张图片；单张文档限 12 MB，画布库合计限 40 MB、50 张画布。文本、规则草稿与全部图片随完整包导出；文献链接保留 ID，目标库不存在该文献时显示缺失提示。
