# Markdown 批量文献信息规范（版本 1）

推荐使用程序内「批量导入 → 按当前 PDF 文件名下载 MD 模板」，或同目录 `metadata-template.md`。一份文件可包含多个 `## 文献` 区块，每个区块对应一份 PDF。不要修改 PDF 文件名；匹配忽略大小写与目录前缀。

```markdown
# Materia 文献批量元数据

格式版本: 1

## 文献 1

- 文件名: paper-one.pdf
- 标题: 完整文献标题
- 发表年份: 2025
- 期刊: 期刊完整名称
- DOI:
- 标签: 二维材料；界面工程
- 影响因子:
- 指标年份:

### 作者与机构

| 作者 | 机构 |
| --- | --- |
| 作者一 | 所属机构一；所属机构二 |
| 作者二 | 所属机构二 |

### 性能参数

| 样品 | 参数名称 | 数值 | 单位 | 测试条件 | 来源 | 限定符 | 误差 |
| --- | --- | --- | --- | --- | --- | --- | --- |

### 文献笔记

#### 笔记 1

填写阅读想法，支持 [[完整文献标题]] 与 [[#二维材料]]。

### 标签笔记

#### #二维材料

填写这个标签下的独立笔记。

## 文献 2

- 文件名: paper-two.pdf
- 标题:
- 标签:

### 性能参数

| 样品 | 参数名称 | 数值 | 单位 | 测试条件 | 来源 |
| --- | --- | --- | --- | --- | --- |
```

以上仅展示文件结构，不附带任何预装文献或性能数据。性能表按以下规则填写：

| 列 | 规则 |
| --- | --- |
| 样品 | 原文样品编号或配方名称。同一文献的多个样品分别记录。 |
| 参数名称 | 只写指标名称，例如比容量、电导率、抗拉强度；不附数值。 |
| 数值 | 只写独立数字，例如 `182.5`、`-0.23`、`1.2e-3`。不能填单位、范围或 `182 ± 2`。 |
| 单位 | 与原文一致，和数值分开。例如 `mAh/g`、`S/cm`、`MPa`；无量纲可写 `1`。 |
| 测试条件 | 温度、电流密度、倍率、循环次数、压力、测试方法等。条件不同的数据分别记录。 |
| 来源 | 页码、图号、表号等原文出处，便于核查。 |
| 限定符 | 可选：`≈`、`>`、`<`、`≥`、`≤`。数值列仍只填数字。默认作图排除这些界限值。 |
| 误差 | 可选，填非负数字，与数值使用相同单位；不填写 `±` 符号。 |

表格单元格中若需要竖线，写成 `\|`。机构用分号分隔。缺失内容保持空白，不估算、不生成数据。空字段与空表不会清空已有记录；非空性能表会替换该篇当前性能参数，所以再次导入时应包含需要保留的全部参数行。标签追加，笔记按内容去重追加。

可交给其他 AI 的提示：

> 按本文件版本 1 规范，为所给 PDF 生成一份可导入的 Markdown。每篇使用独立的 `## 文献` 区块，保留原始 PDF 文件名。记录全部作者及对应机构，按原文提取标签和重要性能参数。参数名称、数值、单位、样品、测试条件、来源必须分列；不同样品或条件分别成行，不把性能数值合并进参数名称或标签。数值只填写数字，约数、界限和误差使用独立列。不推测缺失信息，不生成影响因子，未提供的字段留空。

## 兼容旧版 JSON 与期刊指标

先导入 PDF，再在「备份与设置」中导入元数据。程序不会分析 PDF。

## 文献 JSON

```json
{
  "papers": [
    {
      "filename": "your-paper.pdf",
      "title": "完整文献标题",
      "authors": [
        { "name": "作者一", "affiliations": ["大学材料学院", "研究所"] },
        { "name": "作者二", "affiliations": ["研究所"] }
      ],
      "journal": "期刊完整名称",
      "year": "2025",
      "doi": "",
      "tags": ["二维材料", "界面工程"],
      "impactFactor": null,
      "impactYear": ""
    }
  ]
}
```

也可直接提供文献数组。按 id、原始文件名 filename、DOI、标题依次匹配已有文献。重名歧义将跳过，并在预览中显示。未提供的字段保留，提供空值则清空。tags 为字符串数组，authors 包含全部作者，affiliations 为各自机构数组。

year 为论文发表年份，impactYear 为 IF 指标年份。使用期刊表指标时保留 impactFactor 为 null；手动填 IF 时应同时填写指标年份。

## 期刊 CSV / TSV

```csv
journal,impactFactor,year,source
"期刊完整名称",0.0,2025,"请替换为实际数据与来源"
```

以上仅为格式示例，不是真实指标。IF 是非负有效数字，year 是四位指标年份。含逗号的期刊名用双引号括起，也支持制表符分隔，以及中文表头「期刊、影响因子、年份、来源」。

## 期刊 JSON

```json
{
  "journals": [
    { "journal": "期刊完整名称", "impactFactor": 0.0, "year": "2025", "source": "请替换为实际来源" }
  ]
}
```

也支持直接提供指标数组。同一期刊同一年更新，其余年份保留；匹配忽略大小写和多余空格。请使用与文献元数据一致的完整期刊名。
