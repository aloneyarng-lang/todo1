# Markdown 批量文献信息规范（版本 2）

数据结构是「文献 → 多个材料 → 各材料的性能参数」。推荐在程序内「批量导入 → 按当前 PDF 文件名下载 MD 模板」，或使用同目录 `metadata-template.md`。每个 `## 文献` 区块对应一份 PDF，`### 材料` 下可包含多个 `#### 材料` 区块；每个材料的 `##### 性能参数` 表仅属于该材料。复制材料区块即可继续添加，不限制为模板中的两个。

```markdown
# Materia 文献批量元数据

格式版本: 2

## 文献 1

- 文件名: paper-one.pdf
- 标题: 完整文献标题
- 发表年份: 2025
- 期刊: 期刊完整名称
- DOI:
- 标签: 二维材料；界面工程
- 影响因子:
- 指标年份:

### 作者与机构

| 作者 | 机构 |
| --- | --- |
| 作者一 | 所属机构一；所属机构二 |
| 作者二 | 所属机构二 |

### 材料

#### 材料 1

- 名称: 请替换为第一个材料的名称
- 成分 / 配方:
- 说明:

##### 性能参数

| 样品 / 批次 | 参数名称 | 数值 | 单位 | 测试条件 | 来源 | 限定符 | 误差 |
| --- | --- | --- | --- | --- | --- | --- | --- |

#### 材料 2

- 名称: 请替换为第二个材料的名称
- 成分 / 配方:
- 说明:

##### 性能参数

| 样品 / 批次 | 参数名称 | 数值 | 单位 | 测试条件 | 来源 | 限定符 | 误差 |
| --- | --- | --- | --- | --- | --- | --- | --- |

### 文献笔记

#### 笔记 1

填写阅读想法，支持 [[完整文献标题]] 与 [[#二维材料]]。

### 标签笔记

#### #二维材料

填写标签下的独立笔记。

## 文献 2

- 文件名: paper-two.pdf
- 标题:

### 材料

#### 材料 1

- 名称:
- 成分 / 配方:
- 说明:
```

此模板仅展示结构，不附带预装文献或性能数据。填写规则：

| 字段 | 规则 |
| --- | --- |
| 名称 | 有内容的材料必须填写名称。一个文献可有多个材料，也可先只登记材料，稍后补参数。 |
| 成分 / 配方 | 按原文填写化学组成、配方等，可留空。 |
| 说明 | 单行材料说明，例如制备方法、结构、处理状态等，可留空；长篇阅读记录放入文献笔记。 |
| 材料ID | 可选字段，格式 `- 材料ID: alloy-a`，同一文献内必须唯一，只用字母、数字、下划线和短横线。未填写时按区块顺序生成；重新导入时保留 ID 可稳定标识材料，同名材料可用不同 ID 区分。 |
| 样品 / 批次 | 材料内部的样品编号或批次；也兼容列名「样品」。不同材料可使用相同样品编号，配对绘图不会跨材料。 |
| 参数名称 | 只写指标名称，不附数值。 |
| 数值 | 独立数字，例如 `182.5`、`-0.23`、`1.2e-3`。不可填单位、范围或 `182 ± 2`。 |
| 单位 | 与原文一致，和数值分开；无量纲可写 `1`。 |
| 测试条件 | 温度、电流密度、倍率、循环次数、压力、方法等；不同条件分别成行。 |
| 来源 | 页码、图号、表号等原文出处。 |
| 限定符 | 可选：`≈`、`>`、`<`、`≥`、`≤`；数值列仍只填数字。 |
| 误差 | 可选，填与数值同单位的非负数字，不填 `±` 符号。 |

表格内的竖线写成 `\|`；机构以分号分隔。文件名须保留原始 PDF 名称，匹配忽略大小写与目录前缀。缺失内容留空，不推测或生成数据。新格式的性能表必须写在材料区块中，不再使用文献级 `### 性能参数`。

**更新已有文献：**文献空字段、作者空表和全部空白的材料模板保留原数据；非空材料区块会整体替换该篇的材料列表及各自参数，必须包含所有需要保留的材料。一个具名材料的空参数表表示该材料目前没有参数；删掉其他材料区块后重新导入，会移除那些材料。标签追加，笔记按内容去重追加。仅需更新部分材料时，请在界面「管理材料 / 参数」中编辑，以免遗漏。JSON 明确提供 `materials: []` 或在编辑器中移除所有材料后保存，可清空材料。

**兼容旧数据：**仍支持版本 1 Markdown 和文献级 `measurements` JSON；旧性能记录按「样品」分组为材料，样品为空的归入「未命名材料」。原数值、单位、条件、来源和误差保留，不猜测成分。旧库读取时兼容显示，在编辑并保存文献或导出完整备份时使用新材料结构。版本 1 的非空性能表会替换文献的全部材料参数，因此后续编辑建议改用版本 2。

可交给其他 AI 的提示：

> 按本文件版本 2 规范为所给 PDF 生成可导入的 Markdown。每篇使用独立的 `## 文献` 区块，保留原 PDF 文件名、全部作者及对应机构。先识别文献中的不同材料，在 `### 材料` 下分别使用 `#### 材料 1` 等区块，填写各自名称、成分和说明；每个材料下用 `##### 性能参数` 表填写其数据。参数名称、数值、单位、样品或批次、测试条件、来源分列，不将不同材料混到同一表中。不把数值写进材料名或标签，不推测缺失信息，不生成影响因子。更新已有文献时包含全部要保留的材料及参数。

## 兼容旧版 JSON 与期刊指标

先导入 PDF，再在「备份与设置」中导入元数据。程序不会分析 PDF。

## 文献 JSON

```json
{
  "papers": [
    {
      "filename": "your-paper.pdf",
      "title": "完整文献标题",
      "authors": [
        { "name": "作者一", "affiliations": ["大学材料学院", "研究所"] },
        { "name": "作者二", "affiliations": ["研究所"] }
      ],
      "journal": "期刊完整名称",
      "year": "2025",
      "doi": "",
      "tags": ["二维材料", "界面工程"],
      "impactFactor": null,
      "impactYear": "",
      "materials": [
        { "id": "material-1", "name": "材料名称", "composition": "", "description": "", "measurements": [] }
      ]
    }
  ]
}
```

也可直接提供文献数组。按 id、原始文件名 filename、DOI、标题依次匹配已有文献。重名歧义将跳过，并在预览中显示。未提供的字段保留，提供空值则清空。materials 数组保存材料，各材料的 measurements 数组保存性能参数；不要再同时提供文献级 measurements。tags 为字符串数组，authors 包含全部作者，affiliations 为各自机构数组。

year 为论文发表年份，impactYear 为 IF 指标年份。使用期刊表指标时保留 impactFactor 为 null；手动填 IF 时应同时填写指标年份。

## 期刊 CSV / TSV

```csv
journal,impactFactor,year,source
"期刊完整名称",0.0,2025,"请替换为实际数据与来源"
```

以上仅为格式示例，不是真实指标。IF 是非负有效数字，year 是四位指标年份。含逗号的期刊名用双引号括起，也支持制表符分隔，以及中文表头「期刊、影响因子、年份、来源」。

## 期刊 JSON

```json
{
  "journals": [
    { "journal": "期刊完整名称", "impactFactor": 0.0, "year": "2025", "source": "请替换为实际来源" }
  ]
}
```

也支持直接提供指标数组。同一期刊同一年更新，其余年份保留；匹配忽略大小写和多余空格。请使用与文献元数据一致的完整期刊名。

新版导出的完整备份和已保存材料的桌面文献库使用格式版本 2；本程序同时支持读取版本 1。旧版程序会拒绝打开新版文件，以免遗漏材料数据。
