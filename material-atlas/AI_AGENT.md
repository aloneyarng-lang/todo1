# AI 研究助手

从左侧工具栏的「AI 研究助手」线性对话图标或展开导航后的同名入口打开。

## 配置与使用

1. 点击右上角「对话操作 → 服务设置」，填写 OpenAI 兼容服务的 API 地址（例如 `https://api.example.com/v1`）、模型 ID 和密钥。
2. 根据服务选择 **Chat Completions** 或 **Responses**。模型必须支持工具调用；部分 OpenAI 模型的工具调用需要 Responses。支持填写完整 `/chat/completions` 或 `/responses` 地址，模块会规范为服务根地址。无需密钥的本机兼容服务可留空密钥。
3. 保存设置，选择「整个文献库」或「当前选中文献」。后者使用列表中勾选的文献；未勾选时使用当前打开的文献。空选择会阻止发送，不会退回全库。
4. 提问，例如「检索高熵合金相关文献」「根据笔记梳理信息缺口」「比较已录入的屈服强度，保留样品、单位和测试条件」。支持 `Ctrl+Enter` 发送、多轮追问、停止生成及新对话。
5. 回答中的有效引用和下方「本次检索来源」可点击打开对应文献详情。切换文献范围会新建对话，原对话保存在历史中。切换文献库会停止当前请求并读取新文献库的聊天历史。

启动桌面版：在本目录运行 `npm install`、`npm start`。浏览器预览：`npm run preview`，打开终端显示的本机地址。原始文献库的浏览器与桌面存储相互独立。

聊天中的提问和回答以 Markdown 排版，支持标题、加粗/斜体、列表、表格、引用、链接、行内代码和代码块。有效文献引用仍可点击跳转；代码里的引用保持原样。表格与长代码可横向滚动，网页链接在外部浏览器打开。HTML 原样显示，Markdown 图片显示替代文本，不加载远程图片。

## Google AI Studio / Gemini 配置

Google 官方兼容地址填写 `https://generativelanguage.googleapis.com/v1beta/openai`，协议选择 **Chat Completions**。当前适配器会明确拦截此地址与 Responses 协议的错误组合；Google 原生 `/v1beta` 地址不能直接作为 OpenAI 兼容地址使用。`AQ.` 前缀的新密钥可以正常填写。

「测试连接」只查询模型列表，不发送问题或文献，也不保存表单。程序识别 Gemini 模型 ID 的 `models/` 前缀；列表没有匹配项时会显示服务返回的部分 Gemini ID，并在模型输入框提供候选项。选择确切 ID 后重新检测，再点击「保存设置」。HTTP 200 表示服务接受了模型列表请求，不代表已经验证模型生成、工具调用、地区权限或额度。没有开启系统加密记住密钥时，重启后仍需重新填写。

官方说明：[OpenAI 兼容接口](https://ai.google.dev/gemini-api/docs/openai)、[Gemini API 密钥](https://ai.google.dev/gemini-api/docs/api-key)。

## 聊天历史

发送问题及收到回答后自动保存聊天；重新打开程序或刷新页面后恢复上次对话。点击「对话操作 → 历史记录」可按标题或内容搜索、打开并继续旧对话，或点「新对话」另开一条。新建对话、修改服务设置不会删除之前的聊天。删除某条历史需要再点一次「确认删除」，不影响其他聊天或文献。

继续旧聊天会沿用该对话首次提问时的文献范围（「该对话文献」），不跟随当前列表中另一组勾选项改变；可切换范围另开对话。聊天完整内容在本地保留，续聊时向模型提供最近 12 条非错误消息。支持最多 200 个对话、每个 1000 条消息、合计 20 MB；达到限制时提示整理历史，不会静默丢弃旧消息。

桌面版历史按文献库分别保存在 `ai-chats.json`，写入时保留上一次成功版本 `ai-chats.previous.json`，原文件损坏时不会自动覆盖。更换电脑或备份聊天时请复制这两个文件或整个文献库文件夹；原有文献 JSON 备份暂不包含单独的聊天文件。浏览器预览版保存于当前站点的本地数据库。历史文件仅包含消息和来源字段，不保存服务密钥。旧版本关闭前未保存的对话无法从历史中补回。

## 数据与能力边界

Agent 可调用四个本地只读工具：文献库概览、关键词检索、文献与笔记读取、原始性能记录比较。资料按问题检索后交给模型，并非一次上传全部文献库。每轮最多 4 个工具调用，每次提问最多 6 轮；结果包含截断提示。不同单位不换算、不平均，保留样品、条件、来源、限定符及原始误差。

发送问题会将问题、当前会话以及工具检索到的文献元数据、文献/关联标签笔记、性能参数发送到配置的服务。**不读取或上传 PDF 全文，不具备执行命令、访问任意文件、修改或删除文献的工具。** 模型回答仍需对照原始文献核实；来源列表表示本次实际检索的文献，不能自动保证模型每句话都正确。

桌面版的服务配置位于 Electron 用户配置目录的 `ai-agent.json`，与文献库及其备份分开。默认密钥仅在本次应用运行内保留；主动勾选「用系统加密记住密钥」后使用 Electron `safeStorage` 加密。密钥不回传给页面，不写入聊天记录、文献库、备份或仓库；关闭记住或点击清除会移除保存的密钥。系统加密不可用时只能使用会话密钥。更换服务地址会清空原服务密钥，避免误发。

浏览器预览版的密钥只在页面内存中保留，刷新后需重新填写；地址、模型和协议可以保存，历史聊天按上文说明保存。预览请求经过本机同源代理，不将服务密钥放进 URL，不绕过证书验证。仅允许 HTTPS 服务及本机 HTTP 服务，禁止重定向，支持取消、90 秒单次服务超时、300 秒桌面总超时及错误提示。

## 模块与验证

- `dist/ai-agent-core.js`：共享工具、范围隔离、来源跟踪与有界 Agent 循环。
- `dist/ai-agent.js` / `ai-agent.css`：对话侧栏、服务设置、停止操作和文献跳转。
- `desktop/agent.mjs`：兼容 API 适配、配置校验及加密密钥存储。
- `dist/agent-history.js` / `desktop/agent-history.mjs`：历史格式、容量校验与按文献库隔离的原子保存。
- `desktop/main.mjs` / `preload.cjs`：受限制的桌面通信接口。
- `desktop/agent-http.mjs`：浏览器预览的本机同源代理。
- `tests/agent.test.mjs`：范围、检索、模型循环、协议、密钥及代理测试。
- `scripts/verify-agent.cjs`：使用模拟服务的独立界面流程验证，不调用真实 AI。

执行 `npm test`、`npm run check`、`npm run verify:agent` 和 `npm run verify:agent-desktop` 验证。最后一项使用真实 Electron 主进程、预加载接口和系统加密，配合独立测试文献库及隐藏窗口。真实 AI 调用需要你自己的服务地址、模型与密钥，验证流程不消耗真实模型额度。

研究助手已支持“文献 → 材料 → 性能参数”。可按材料名称、成分、说明搜索，读取结果包含材料信息，原始观测携带材料 ID 和名称，比较时保留各自归属。不会跨材料拼接不同性能指标，也不会推测旧数据的材料成分。


## 翻译功能共用服务设置

PDF 划词和对照翻译沿用此处的服务地址、模型、协议和密钥，翻译请求不启用工具调用。研究对话仍仅使用文献目录、笔记和性能参数；翻译会把选文或主动翻译的页面文字发送到该服务，PDF 文件保留本地。生词本和译文纳入完整备份，密钥不纳入。使用方法见 [TRANSLATION.md](TRANSLATION.md)。


## 密钥状态与 HTTP 401（v1.4.1）

服务设置现在会显示密钥是已载入、仅本次有效，还是未载入。未勾选系统加密记住密钥时，关闭程序后会清除密钥，但仍保留地址和模型；下次需重新填写。DeepSeek 和 OpenAI 官方服务未载入密钥时会先打开设置并提示，聊天和翻译均不会发送空密钥请求。无密钥的本机服务和其他兼容服务仍可使用。

HTTP 401 表示服务认证失败：先确认密钥属于当前 API 地址并仍有效，再在设置中替换保存。HTTP 403 则检查账号和模型访问权限。程序不展示服务返回的原始错误正文，避免其中包含密钥。粘贴带 Bearer 前缀的密钥时会自动移除重复前缀。


## 测试连接（v1.4.2）

设置中的「测试连接」只向当前地址发送 GET /models，不发送问题、文献或生成请求。可检测尚未保存的输入；密钥栏留空且地址与已保存地址相同时复用当前进程中的密钥，改变地址则不会向新地址复用旧密钥。检测不会保存设置或替换已保存密钥。

结果显示当前版本、服务域名、模型、请求是否附带密钥、HTTP 状态及模型是否出现在列表中。若「已附带密钥 · HTTP 401」，说明测试请求确实带了凭据，但服务未接受；请核对官方平台密钥是否仍有效。模型列表检测成功不代表所有生成请求、额度或模型权限都通过。部分兼容服务不支持模型列表，会给出相应提示。

完整密钥中出现空格、引号、非英文字符或星号遮盖值时会先提示修改，不将其作为有效密钥发送。错误结果不会展示服务返回的原始正文或任何密钥字符。
