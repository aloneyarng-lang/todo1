# 主题与外观

点击左侧图标栏下方的调色盘，或「文献库与备份 → 主题与外观」。内置学术纸白、深海蓝、石墨夜读、暖砂手稿、学术紫、维基百科六套主题。学术紫采用雾紫纸底、深紫强调色、香槟金点缀。维基百科采用百科白底、蓝色链接、衬线标题、细灰边线与简洁方角。点击即可切换，选择和导入的主题保存在当前文献库的 `library.json`，重新打开程序后恢复。

字体区域可分别选择「界面与正文」和「文献与页面标题」，并提供中英文实时预览。选项包括跟随主题、微软雅黑、等线、思源黑体、宋体、思源宋体、楷体、Times New Roman、Georgia 和 Arial。使用电脑已安装字体，不下载外部字体；未安装时按后备字体列表显示。

字体选择会在切换内置主题、导入或删除 CSS 主题时保留，并随当前文献库保存。选择「跟随主题」或点击「恢复跟随主题」，可重新使用内置主题或 CSS 文件定义的字体。「导出当前主题」包含实际生效的字体设置。PDF 原文与科研图导出字体不变。

左下角齿轮 →「主题与字体」中的「界面字号」滑块支持 85%–150%，每次调整 5%；键盘方向键同样可用。拖动时即时预览，松开后保存，点击「恢复默认字号」回到 100%。字号应用于菜单、文献列表、详情、笔记和 AI 聊天，切换或导入主题、重启后仍保留。字体种类和字号可分别恢复。字号是当前文献库的阅读偏好，不写入导出的主题 CSS；PDF 原文及页上批注、图谱节点标题和科研图导出仍采用原有尺寸。

可以导入 `.css` 文件。当前采用 **CSS 变量主题格式**，支持配色、字体和圆角；普通 CSS 选择器、布局规则、`@import` 和外部资源不在此格式中。这样无需修改程序代码，也不会因为主题隐藏功能按钮。

在主题窗口点击「下载主题模板」，或使用程序旁的 `theme-template.css`。模板列出了全部变量；可以只保留想修改的变量，其余使用默认值。修改注释中的 `@name` 为自己的主题名称。

```css
/* @name: 我的海蓝主题 */
:root {
  --paper: #edf2f6;
  --surface: #fbfdff;
  --canvas: #f4f8fc;
  --panel: #e8f0f7;
  --sidebar: #e7eef5;
  --ink: #233f55;
  --muted: #667e91;
  --line: #d3e0eb;
  --teal: #285f8a;
  --teal-light: #deebf5;
  --on-accent: #ffffff;
  --radius: 6px;
  --theme-mode: light;
}
```

| 变量 | 用途 |
| --- | --- |
| `--paper` / `--surface` | 程序背景 / 内容面板与弹窗 |
| `--canvas` / `--panel` / `--sidebar` | 星图画布 / 次级底色 / 左侧导航 |
| `--ink` / `--muted` | 正文 / 辅助文字 |
| `--line` | 边线与分隔线 |
| `--teal` / `--teal-light` / `--on-accent` | 主题强调色 / 选中底色 / 强调色按钮上的文字 |
| `--warning` / `--warning-soft` | 提示文字 / 提示底色 |
| `--danger` / `--danger-soft` | 错误文字 / 错误底色 |
| `--shadow` | 阴影颜色，可使用带透明度的八位十六进制颜色 |
| `--sans` / `--serif` | 界面字体 / 文献标题字体，使用电脑已安装字体及后备字体列表 |
| `--radius` | 主要控件圆角，`0px` 至 `20px` |
| `--theme-mode` | `light` 或 `dark`，用于原生输入框、滚动条等控件 |

颜色支持十六进制、`rgb()`、`rgba()`、`hsl()`、`hsla()`。深色主题请同时调整背景和文字；可以先选中「石墨夜读」，导出当前主题后修改。注意正文与背景、按钮文字与强调色之间的对比度。

支持一次多选 CSS 文件，每份不超过 32 KB，最多保存 20 个自定义主题。同名主题再次导入会更新；整批文件通过检查后才保存。导入后可删除源 CSS 文件，程序仍保留已保存的主题。

「导出当前主题」会生成包含全部变量的 CSS，可交给其他 AI 修改，也可在另一台电脑上导入。完整文献备份主要保存文献数据；迁移主题请导出 CSS，或复制整个文献库文件夹。

删除自定义主题不会修改文献；如果删除的是正在使用的主题，会自动回到学术纸白。「恢复默认主题」切换回纸白，并保留已导入主题。

主题覆盖程序界面与星图；星图节点的分类颜色继续表示标签或分组。科研图预览和 PNG / SVG 导出保持白底与独立科研配色。
